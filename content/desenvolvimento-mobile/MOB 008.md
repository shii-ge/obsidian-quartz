# Botões e interação com o usuário

- **Botões no XML.**
	- Geralmente, tag `<button>`
	- `ChipGroup` e `Chip` (botões de seleção)
	- `CheckBox` (caixa de seleção)
	- `RadioGroup` e `RadioButton` (conjunto com apenas 1 seleção)
	- `ToggleButton` (seleção entre dois estados)
	- `SwitchCompat` (seleção entre dois estados)
	- `FloatingActionButton`

É importante, para a posterior associação ao código em Kotlin, dar para cada botão um determinado identificador (*id*).


```xml
<Button  
    android:id="@+id/button1"  
    android:layout_width="wrap_content"  
    android:layout_height="wrap_content"  
    android:text="Botão 1" />
```

```kotlin
val button = findViewById<Button>(R.id.button1)  
button.setOnClickListener {  
    Toast.makeText(this, "Botão clicado!", Toast.LENGTH_SHORT).show()  
}
```

No lugar do `Toast.makeText()`, é possível utilizar outras funções compatíveis com botões:
- `TextView.setText()`: muda o texto de um elemento já existente.
