# Configuração do Android Studio

- **Download:** https://developer.android.com/studio
- **Criação de projeto:**
	- `New Project > Empty Views Activity`
	- Linguagem Kotlin e Kotlin DSL (`build.gradle.kts`)

## Estrutura das pastas

1. ***Manifests*.** Contém o arquivo `AndroidManifest.xml`, basicamente a identificação do projeto. Usa-se esse arquivo para registro de telas, permissões e componentes do *app*.
2. ***Kotlin+Java*.** Pasta onde fica o código do *app*, seja ele em Kotlin ou Java. Criação de classes, telas e funcionalidades.
	- `com.example.{nome}`: pacote principal do *app*
3. ***Res*.** Pasta de recursos do *app*, como imagens, *layouts* e textos.
	- `drawable`: imagens e recursos visuais;
	- `layout`: arquivos XML para organizar as telas;
	- `mipmap`: ícones do *app*;
	- `values`: guarda textos, cores, estilos e tamanhos (arquivos como `strings.xml`, `colors.xml`);
	- `xml`: outros arquivos de configuração, como preferências do usuário.
4. ***Gradle Scripts*.** Arquivos de configuração do *Gradle*, controlando como o *app* é construído.
	- `build.gradle.kts (Project: )`: configurações gerais do projeto;
	- `build.gradle.kts (Module: app)`: configurações específicas, como dependências e versões;
	- `proguard-rules.pro`: configurações para ofuscar e minimizar o código;
	- `gradle.properties`: propriedades do projeto *Gradle*;
	- `gradle-wrapper.properties`: configurações do *Gradle Wrapper*;
	- `libs.versions.toml`: catálogo de versões para dependências;
	- `local.properties`: define a localização do SDK do Android;
	- `settings.gradle.kts`: configurações do projeto, quais módulos incluir.
