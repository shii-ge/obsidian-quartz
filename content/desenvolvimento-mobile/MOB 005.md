# Introdução à linguagem Kotlin

- **Kotlin** foi lançada em 2011 para JVM, depois de um ano em desenvolvimento.
- Linguagem de alto nível orientada a objetos, de plataforma cruzada e multiparadigma. Interoperável com Java.
- Apps Android nativos, JVM, *backend*, *Data Science*, etc.

## Sintaxe

1. **Funções.**

```kotlin
fun main() {
	println("Olá, Kotlin!")
}

fun soma (a: Int, b: Int): Int {
	return a+b
}

fun saudacao (nome: String = "Usuário") {
	println("Olá, $nome!")
}
```

2. **Variáveis.**

```kotlin
fun main() {
	var nome = "João" // variaveis mutaveis
	val texto = "Oi" // variaveis imutaveis
}
```

3. **Estruturas condicionais.**

```kotlin
if (cond) {
	// operacoes
}

when (switch) {
	1 -> println("1")
	2 -> println("2")
	3 -> println("3")
}
```

4. **Laços de repetição.**
	- `1..5`: inclui do 1 ao 5;
	- `1 until 5`: exclui o 5;
	- `1..10 step 2`: do 1 ao 10, pulando de 2 em 2;
	- `5 downTo 1`: ordem decrescente.

```kotlin
for (i in 1..5) {
	println("Número: $i")
}

while (cont < 5) {
	// operacao
	cont++
}
```

5. **Captura de entrada.**

```kotlin
fun main() {
	println("Digite seu nome: ")
	val nome = readLine()
	println("Olá, $nome!")
}
```

6. **Classes.**

```kotlin
class Pessoa (val nome: String, var idade: Int) {
	fun apresentar() {
		println("Olá! Meu nome é $nome e tenho $idade anos!")
	}
}

fun main() {
	val pessoa1 = Pessoa("Maria", 21)
		pessoa1.apresentar()
}
```
