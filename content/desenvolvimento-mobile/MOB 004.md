# Criando um *app* no Android Studio

## Componentes principais

1. *Common.* Componentes mais utilizados. `TextView`, `Button`, `ImageView`
2. *Text.* `TextView`, `EditView`
3. *Buttons.* `Button`, `ImageButton`, `Switch`
4. *Widgets.* `ProgressBar`, `SeekBar`, `CalendarView`
5. *[[MOB 007|Layouts.]]* `LinearLayout`, `RelativeLayout`, `ConstraintLayout`
6. *Containers.* `ScrollView`, `RecyclerView`, `FragmentContainerView`
7. *Helpers.* `Space`, `Barrier`
8. *Google.* `AdView`, `MapView`
9. *Legacy.* `ListView`, `GridLayout`

## Inserindo uma imagem

- Coloque a imagem na pasta `res/drawable/`
- Abra o arquivo de layout `activity_main.xml` (ou qualquer for o nome da *activity*)
- Usar o componente `ImageView` para selecionar a imagem

## Modificando o ícone

- Coloque o ícone na pasta `res/mipmap/`
- Abra o arquivo `AndroidManifest.xml`
- Alterar o campo desejado:
	```xml
	android:icon="@mipmap/novo_icone"
	```

## Adicionando uma fonte

- Dentro da pasta `res/`, criar uma nova pasta chamada `font` (New - Android Resource Directory)
- Colocar o arquivo da fonte nessa pasta
