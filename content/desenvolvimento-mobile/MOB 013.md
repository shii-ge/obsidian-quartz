# Aula 13 - Introdução a APIs REST

**Fluxo de requisições a APIs.** Requisição GET -> resposta JSON -> interpretar na interface.

## Retrofit

O **Retrofit** é uma biblioteca Android que faz a comunicação e consumo de APIs REST. Ele facilita o processo de requisições HTTP ao converter automaticamente as respostas JSON em objetos e classes do Kotlin.

```
com.seuprojeto.app/
|- MainActivity.kt
|- Post.kt (modelo dos dados, estrutura JSON) (kotlin)
|- ApiService.kt (interface com os endpoints da API)
|- RetrofitInstance.kt (instância e configuração do Retrofit)
```

- **Requisitos básicos:**
	- Projeto Android configurado com **minSdk 21+**;
	- Permissão de uso da Internet no `AndroidManifest.xml`.
	- Adicionar as dependências no Gradle.

```xml
implementation("com.squareup.retrofit2:retrofit:2.9.0")
implementation("com.squareup.retrofit2:converter-gson:2.9.0")
```
