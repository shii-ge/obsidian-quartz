# Recursos de layout no Android

**Layout.** Disposição visual de elementos na tela. Hierarquia de layout. Árvore de visualização. Um layout principal (`ViewGroup`) contém várias *views* (texto, imagem, botão), e cada *view* pode ter atributos específicos como altura, largura, posição.

- `ConstraintLayout`
- `LinearLayout`: organização enfileirada horizontal ou verticalmente
- `RelativeLayout`: posicionamento de um componente em relação a outro
- `FrameLayout`: distribuição igual para todos os elementos
- `ScrollView`: rolar.
- `GridLayout`: disposição em grade dos elementos
- `TableLayout`
- `AbsoluteLayout`: posicionamento exato dos componentes

Dentro da *tag* de layout, a primeira coisa que aparece são as suas definições gerais, que não devem ser alteradas.

- layout width/height: "match-parent" (ocupa a tela toda)
