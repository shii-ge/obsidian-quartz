# Persistência de dados

- Técnica que permite o armazenamento de dados de forma que persistam entre diferentes execuções do aplicativo.
    - `SharedPreferences`: armazenamento de pares chave-valor.

| Chave   | Valor        |
| ------- | ------------ |
| "Texto" | "Olá, Mundo" |

```kotlin
private val PREFS_NAME = "MyPrefs"
val sharedPreferences: SharedPreferences = getSharedPreferences(PREFS_NAME, Context.MODE_PRIVATE)
```

- **Leitura de dados.**
```kotlin
val name = sharedPreferences.getString(KEY_NAME, "")
```

- **Salvar dados.**
```kotlin
val editor = sharedPreferences.edit()
editor.putString(KEY_NAME, nameToSave)
editor.apply()
```
