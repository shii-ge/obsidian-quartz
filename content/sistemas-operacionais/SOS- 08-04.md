# Funções em shell

- Exemplo de função em shell.

```sh
#!/bin/sh

sim_ou_nao() {
	echo "Seu nome é $*?"
	while true
		do
			echo -n "Responder sim ou nao: "
			read x
			case "$x" in
				s | sim ) return 0;;
				n | nao ) return 1;;
				* ) echo "Resposta errada."
			esac
		done
}

echo "Parametros: $*"
if sim_ou_nao "$1"
	then
		echo "Ola $1, belo nome."
	else
		echo "Deixa pra lá."
	fi
exit 0
```

## Operações de cálculo

Em *shell*, todo tipo de conteúdo é considerado texto, inclusive números. Portanto, para realizar um cálculo na linha de comando é necessário usar o comando `expr` ou a sintaxe `$((operacoes))`.

```sh
expr 1 + 1 # retorna 2, espacos necessarios para separar os elementos
expr 20 \* 5 # retorna 4, a barra é necessaria pois o asterisco é um caractere especial

a=2 # note que, para associacoes de variaveis, nao ha espaço
num=3
expr "$a" + "$num" # retorna 5
```

Outros comandos do `expr` incluem:

- `expr length <x>`: retorna o comprimento da string.

O *bash* não possui suporte para operações de ponto flutuante (*float*), por isso é necessário utilizar o comando `bc`, um binário para cálculos.

Operações: +, -, \*, /, \%, /sqrt, ^, s(x), c(x), l(x) (logaritmo natural), e(x)

```shell
echo "(20+5)/5" | bc
echo '100.098*(1+0.22)' | bc

lat1=-23.6855443
lat2=-23.6555284
echo "scale=2;($lat1+$lat2)/2" | bc
```
