# Scripts em *shell*

- **Dois paradigmas** para programas.
	- Compilados (código fonte gera um binário);
	- Interpretados (código fonte é interpretado).

> **Processo de criação de *scripts*.**
> 1. Editar o código-fonte.
> 2. Salvar o arquivo.
> 3. Compilar código em binário (compilado) ou atribui a execução (interpretado).
> 4. Execução do programa.

## Estrutura `for`

```shell
for variavel in valores
do
	# comandos
done
```

```shell
for i in 1 2 3 4 5; do
	# comandos
done
```

## Estrutura `while`

```shell
while condicao do
	#comandos
done
```
